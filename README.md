## 🖥️ About The Project

**ADITYA.OS** is my personal portfolio website built with a unique **Operating System inspired user interface**.

Instead of presenting information through a traditional portfolio layout, this website provides an interactive desktop-like experience where visitors can explore my profile, technical skills, projects, internships, hackathons, certifications, achievements, and contact information through a modern UI.

The project focuses on creativity, smooth user interaction, responsive design, glassmorphism styling, neon visuals, and a polished developer experience.

* 🔋 Live battery status display
* 🕒 Real-time clock in footer system panel
